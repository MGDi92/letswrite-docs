# Lets Write — openbare documentatie

Welkom bij de openbare documentatie van Lets Write.

Deze repository is bedoeld voor de projectintroductie,
ontwikkelstatus en toekomstige gebruikersdocumentatie.
De applicatiebroncode blijft privé en wordt hier niet gepubliceerd.

## Ontwikkelstatus

Lets Write bevindt zich in de ontwikkel- en testfase.
Onderdelen worden stapsgewijs gebouwd, gecontroleerd en gedocumenteerd.

Deze repository bevat geen productieversie of installatiepakket.
Informatie over geplande onderdelen is geen bevestiging dat die
onderdelen al publiek beschikbaar zijn.

## Wat we hier documenteren

- Een introductie van het project.
- Ontwikkelupdates met onderscheid tussen gepland, gebouwd en getest.
- Uitleg en gebruikershandleidingen zodra onderdelen daarvoor klaar zijn.

## Omgaan met vertrouwelijke gegevens

Deze repository is uitsluitend voor bewust openbare documentatie.

Plaats hier geen privésleutels, herstelzinnen, wachtwoorden,
API-sleutels, persoonlijke gebruikersgegevens of interne configuratie.
Kopieer geen volledige lokale projectmappen naar deze repository.
